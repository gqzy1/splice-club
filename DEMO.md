# Playing SPLICE.CLUB

## Before deployment

Run `npm ci` and `npm run dev`. First visits open a local interactive tutorial:

1. START PLAYING; choose Moon Laundry.
2. Add Jelly Radio or Pocket Planet. Desktop supports dragging; mobile supports tapping and swiping the ingredient shelf.
3. ACTIVATE FUSION. Skip the animation if desired.
4. Flip the creation for its description, traits and source notes.
5. Explore the clickable parent/child ingredient map.
6. Enter the real playground. HOW TO PLAY reopens the tutorial.

Every example is OFFCHAIN DEMO / LOCAL PLAY MODE. Completing or skipping is remembered in browser storage. These objects are not onchain works and never populate the real gallery.

 The empty gallery, status notice and disabled write button are deliberate. Open the seed form to draft an idea. `?w=1` displays the honest unverified demo state. No example wallet, work or transaction is fabricated.

## After deployment and activation

1. Browse without connecting a wallet. Open a seed card to read its details and contribution address.
2. Drag two seeds into the Playground or use “Splice me”. The two seed creators must be different addresses.
3. Connect a browser wallet on Stable Studionet. Click “LET’S SPLICE” and confirm the real transaction.
4. Follow submission, consensus and finalization. Do not submit again while a hash is waiting; use read-only recheck after interruption.
5. A verified readback unlocks the reveal. Open “Follow its roots” to inspect both full parents and creator addresses.
6. To contribute a seed, enter a name, description and 1–3 distinctive features. Explicitly choose public derivation permission and register onchain.

`?w=1` opens the recorded real work and lineage once `verifiedWorkId` has been established through live evidence. It never fills the gallery with fixtures. Only tests import synthetic onchain fixture data; the tutorial uses an independent local-only object type.

V1 supports two seeds → one child. Fusions cannot become parents yet. There is no NFT mint, trade, token, image API or royalty flow.
