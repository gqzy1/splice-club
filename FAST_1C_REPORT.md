## Design and working experience

The home composition is rebuilt around an asymmetric near-viewport violet stage. REMIX / THE / POSSIBLE uses solid, outline and acid-lime lettering; the reactor occupies the second visual plane. Its real selection slots and real guarded submission control are inside this hero. Floating LOCAL / OFFCHAIN STUDY cards open the tutorial and cannot enter the onchain gallery. These new entries disable while a real operation is active, just like the original tutorial entry.

A shared `ReactorVisual` constructs the chrome/plastic pod, face window, front/back orbit, energy beads and soft pedestal using CSS. It is an artistic visualization, not an AI agent or proof of network activity. Selected local inputs converge during the original 2.2-second fusion interval. Reveal releases a radial scene and material card. Pointer position controls bounded hover tilt; drag shows source feedback and the target highlights. All motion uses transform/opacity where practical. Reduced motion removes scene, pod and card animations and keeps instant reveal.

The seven tutorial steps, selection gates, click and drag selection, replacement/removal, skippable animation, result flip, node inspection, restart and completion memory remain intact. The skip-animation control reserves its layout space while hidden so becoming available does not resize the stage. Tutorial data types, isolated state, drag payload and persistence design are unchanged. Every scene identifies OFFCHAIN DEMO / LOCAL PLAY MODE. Prewritten results still disclose that no AI request, validator execution, transaction or registration occurred.

Lineage uses a tilted, layered origin room, an orbital reference plane, connecting branches, focus outlines and an interactive description/trait panel. Selecting a node brings that exact origin into focus. Parent relationships remain the actual pair. The real work dialog similarly displays only the returned parent IDs, contributors and metadata, with graphical nodes added to those existing reads.

The collection uses staggered cards on desktop. The honestly empty real gallery offers local practice; it contains no invented chain work. Mobile uses a touch-swipe shelf, stacked reactor inputs and full-width activation. Navigation, draft form and close controls remain available.
