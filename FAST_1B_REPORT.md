## Experience

Ivory, acid lime, punch orange and cobalt form a split editorial stage and a tactile creative toy. Moon Laundry, Jelly Radio and Pocket Planet use distinct local SVG studies, collectible card edges, typographic serials and selected outlines. Mobile uses a swipeable ingredient shelf. The fusion engine has a soft radial light field, orbit rings, a transforming central mark and clear ingredient/ready/running states. Reveal gives the creation a separate entrance; reverse notes explain its name, traits and sources. Clickable parent/child nodes animate their connecting strokes.

Tutorial steps: Welcome → first selection → second selection → activate machine → reveal/flip → lineage → real playground. Selection gates progression. Remove and replace work before activation. Animation lasts 2.2 seconds, can be skipped and becomes immediate for reduced motion. Exit and restart stay available. Completion or skipping is remembered locally. HOW TO PLAY reopens the full flow. The direct `?w=1` entry retains the existing read-only verification route.

Formal navigation exposes PLAY, EXPLORE, CREATE and HOW TO PLAY on all inspected sizes. The real machine has refined surfaces and selection/reveal transitions; its empty gallery offers local practice. Existing wallet, transaction recovery, real reads and create form remain implemented. Switching to the tutorial is disabled during an active real operation.

## Honest separation

Local `DemoIdea` objects have no onchain IDs or wallet addresses and never implement the formal Work type. Tutorial state is owned by a separate component; its drag payload is `application/x-splice-demo`, while formal cards use `text/plain`. RealApp is unmounted during local play, so the tutorial cannot invoke its read or transaction handlers. Only the tutorial preference persists. No demo work enters real gallery, statistics or transaction history. Every tutorial scene has OFFCHAIN DEMO / LOCAL PLAY MODE labels. Results disclose a prewritten local rule, with no AI call, validators, transaction or onchain registration.

## Reproduce browser acceptance

The optional browser harness is `scripts/browser-acceptance.cjs`. Supply an installed Playwright module via `SPLICE_PLAYWRIGHT_MODULE` and Chromium path via `SPLICE_CHROMIUM_EXECUTABLE`, then run it after `npm run build` from the repository root. With standard Playwright installation the module variable can be omitted. Browser tooling is external to the app lockfile and production dependencies. The harness starts a local preview, records actual gestures and produces screenshots plus JSON results.
