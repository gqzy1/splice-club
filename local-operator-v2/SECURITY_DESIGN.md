# V2 边界

继承 FAST-2C 的明确 OKX provider、固定 Stable 61999、双RPC链ID/费率核验、独立估费、intent先于签名落盘、Hash恢复、Web Locks、失败停止与凭据字段删隐。

V2 专用目录与端口4180、独立localStorage键、version=2、新SHA、部署目标/父作品version绑定、旧V1地址拒绝。没有自动迁移、清空按钮或证据上传。新地址须从T01真实源码摘要验证后才能进入后续阶段。

FAST-2F 发布锁在 UI 和 prepare/submit 引擎双层生效。当前不能发送交易。只有未来新授权且代码审查后的发布批次才可开放；用户不能靠导入旧Hash完成V2证明。

手工伪造/修改浏览器存储超出此工具防误操作边界，故真实验收仍要求链上原始结果、源码摘要及读回。正确引用也不能保证模型永不误判，人工语义验收仍保留。
